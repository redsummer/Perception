# 无人驾驶环境感知技术教学实验站

主讲教师：夏红阳。面向课程项目教学、硬件在环教学示意及嘉立创EDA接口设计。

本项目是无需构建的静态网站。所有脚本、图片和教学下载文件均使用相对路径，本地双击 `index.html` 即可使用，也适合发布到 GitHub Pages 项目子路径。

## 网站内容

- 课程总览：九项目、三项EDA设计任务、四学期教学实践。
- 项目实验：目标、原理、实验步骤、资料、验收与单题自测；项目完成状态在当前浏览器本地保存。
- 交互实验台：超声波阈值制动、正交编码器计数与转角、二维激光扫描几何示意。支持暂停、重置和导出示意记录CSV。
- 嘉立创EDA：三类传感器的接口逻辑、检查清单、关联项目与Markdown自查单导出。
- 课程资源：9份原始实验指导书、9份上课用PPT及实验报告模板。
- 教学改革：课程任务组织、实物教具与虚拟模型、EDA融入、交付评价。

## 本地使用

打开 `index.html`。建议使用现代Chrome或Edge浏览器。站内操作无需联网；“打开嘉立创EDA”是外部链接，需要网络。浏览器对本地文件的存储策略可能不同；站点不上传学习记录。

需要HTTP预览时，可在本目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。这不是运行本站的必要步骤。

## 后续发布到 GitHub Pages

1. 新建一个用于课程网站的GitHub仓库。
2. 将本目录内的文件放到仓库根目录，确保根目录包含 `index.html`、`styles.css`、`app.js`、`data.js`、`assets/`、`vendor/`、`resources/` 和 `.nojekyll`。
3. 推送后进入仓库 Settings → Pages，在 Source 中选择 Deploy from a branch，选择实际使用的分支（如main），目录选择 `/ (root)`，保存。
4. 等待GitHub Pages生成站点地址。通常为 `https://用户名.github.io/仓库名/`。使用页面提供的地址为准。

本次仅生成本地网站，尚未创建远程仓库或发布。

官方发布说明：<https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>

## 内容维护

- `data.js`：九项目目标、任务、理论、自测题以及EDA接口内容。
- `app.js`：页面路由、交互演示、下载、学习记录与页面文案。
- `styles.css`：桌面与移动布局。
- `resources/`：指导书、课件与报告模板。更新时保留原有文件名，下载入口无需同步修改。
- `assets/`：源指导书中的教具照片与运行截图，以及传感器接口框图参考。
- `SOURCES.md`：资料来源、使用范围与需要后续核实的内容。

## 演示与工程边界

网页没有连接真实硬件，也不执行ROS、嘉立创EDA或Hector SLAM。超声波模型为理想阈值逻辑；编码器模型为理想A/B相四倍频计数；雷达模型为二维射线求交。场景显示和导出的数据均是教学示意，不是实测结果。

原理图页面为接口逻辑说明，无法输出嘉立创EDA原生工程或代替电气规则检查。毫米波雷达为工业软件拓展任务；项目09仍为激光雷达实时建图。实际器件型号、电压、引脚和通信协议需要依据手册确认。
